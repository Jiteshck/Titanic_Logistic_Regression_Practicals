# Titanic Logistic Regression Practicals

This project demonstrates **Logistic Regression** using the Titanic dataset with Python and Scikit-learn.

The model predicts whether a Titanic passenger **Survived or did not Survive** based on passenger information.

## 📌 Project Overview

- **Input:** Passenger information from the Titanic dataset
- **Output:** Survival prediction and survival probability
- `0` → Not Survived
- `1` → Survived

The practical demonstrates the following Machine Learning workflow:

1. Load the Titanic dataset
2. Select useful features
3. Display dataset information
4. Handle missing values
5. Convert categorical values using dummy variables
6. Split data into training and testing sets
7. Create a Logistic Regression model
8. Train the model
9. Predict passenger survival
10. Calculate model accuracy
11. Calculate survival probability
